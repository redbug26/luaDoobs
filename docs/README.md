# Documentation

| File | Contents |
|---|---|
| [`lua4agent.md`](lua4agent.md) | Complete reference for Doobs Lua scripts: the four entry points (`import`, `fetch`, `rule`, `parameters`), `.luaDoobs` files, complete databases `{ libraries = … }`, value format for every field type, library setup, formula syntax, the `doobs` module, sandbox limits, commented examples and a checklist. |

The guide is written so that an **AI agent** can produce a correct script on its own: everything it describes
matches the actual behavior of Doobs, and what it does not describe does not exist. Give it to the agent with
your request, for example: “Create a .luaDoobs file to manage my wine cellar: wines, linked producers, tastings
in a sublist, in French and English.”
